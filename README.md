# Slide

Driver-first navigation that prefers the **smoothest** line.

Pitched 3D map, Tesla/Uber-style HUD, a Garage for paint and camera, and Forza-style ghost cars on your route.

```bash
npm install
npm run dev
```

Open localhost, set From / To, hit **Drop the line**, then **Tune** to customize.

Agents (Cursor, Claude, Grok): start at **[HANDOFF.md](HANDOFF.md)** and **[TASKS.md](TASKS.md)**.
